# NIETM-Chatbot
The NIETM Chatbot is an AI-driven virtual assistant designed to automate student services. It provides instant, 24/7 answers to inquiries regarding admissions, fee structures, faculty contacts, and campus events, reducing the administrative workload and eliminating the need for students to visit the campus in person.

Steps to prun this project

1)Open the Project folder in any Code editor

2)use the following commands in the terminal

  	 Set-ExecutionPolicy Unrestricted -Scope CurrentUser
	
	.venv/Scripts/activate

3)run  python app.py
